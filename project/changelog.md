# 更新记录

> 记录文档项目索引的结构与维护变更。

### 2026-10-04 · 调整索引定位

- 首页与主菜单以「我的记录」和「我的文档」为主，外部参考收纳到独立入口。
- 顶部菜单固定为四个入口，侧栏只展示当前栏目；记录按月份与项目分组，项目说明和缓存刷新放在首页侧栏。
- 实际内容目录按 `notes/`、`docs/`、`external/` 组织，六个外部分类及其总览归入 `external/`。
- 三个内容目录统一去掉下划线前缀，并同步页面、菜单和指南中的路径；Docsify 导航文件保留约定名称。
- 项目说明与更新记录移入 `project/`，同步首页入口并配置独立侧栏。
- 接入项目仓库清单 `project/repositories.md`，在首页与项目侧栏提供统一入口。
- 记录与文档入口目录统一为 `notes/`、`docs/`；项目入口页使用 `README.md`，普通文件和项目目录使用连字符命名，同步全部索引链接。
- 补齐 Spring Data、Spring Cloud、Spring AI 的构建、翻译与排错记录目录。
- 新增文档入口总览，保留各版本文档的相对路径。
- 修正外部分类侧栏中指向不存在页面的链接，并更新项目说明与贡献指南。

### v2.1.0 (2026-06-12)
- **技术生态扩充**：新增后端框架、中间件、云原生、API 与安全、AI 与数据工程、测试与代码质量六个主题索引。
- **语言与前端补全**：增加 Dart、Swift、Ruby、R、Julia、Scala、Elixir、Lua、Angular、Svelte、Astro、跨平台开发及前端工程化资料。
- **数据库扩充**：增加 MariaDB、Valkey、OpenSearch、ClickHouse、DuckDB、时序数据库、图数据库、分布式 SQL 与云数据库文档。
- **本地镜像接入**：新增 Spring AI 1.1.7 与 Blender 5.1 用户手册、中文手册及 Python API 入口。
- **导航重构**：将数据库、消息系统、云原生、API 安全和 AI 数据工程拆分为独立入口，同时保留原有文档路径。

### v2.0.0
- **多目录结构优化**：将原本扁平的文档文件分流至 `java/`、`spring/`、`devops/` 等独立的二级目录，提高可维护性。
- **独立侧边栏机制**：为每个二级目录配置了专用的 `_sidebar.md`，实现按模块聚焦阅读，同时在顶部提供“返回首页”入口。
- **导航精简**：优化顶部导航栏，解耦原本合并的分组，实现 1对1 目录导航。
- **视觉美化与无 Google 字体**：自定义徽章标识（本地 / 在线 / 双通道），全部样式移入前端 CSS 控制，移除 Google Fonts CDN 引用，切换为纯本地系统字体渲染。
- **功能增强**：集成了全局 Search 搜索引擎与 Zoom Image 放大镜。
- **纯粹 Markdown**：首页 `README.md` 放弃自定义 HTML，重构为 100% 纯粹 Markdown 编译。
