# 数据工程与大数据

> 涵盖海量数据处理、流计算与分析平台。

### 📊 数据处理与分析
- **[Apache Spark](https://spark.apache.org/docs/latest/)** — 大规模统一数据分析引擎 `官方在线`
- **[Apache Flink](https://flink.apache.org/what-is-flink/flink-architecture/)** — 有状态流处理平台 `官方在线`
- **[Apache Beam](https://beam.apache.org/documentation/)** — 批处理与流处理统一模型 `官方在线`
- **[dbt](https://docs.getdbt.com/docs/introduction)** — 分析工程与数据转换工具 `官方在线`
- **[Databricks](https://docs.databricks.com/)** — Lakehouse 数据与 AI 平台 `官方在线`

### ⚙️ 分布式计算框架
- **[Ray](https://docs.ray.io/)** — 分布式计算框架，常用于扩展 AI 和机器学习工作负载

### 🗄️ 大数据存储、集成与数仓 (Big Data Storage & Warehousing)
- **[Apache Hive 中文手册](https://www.docs4dev.com/docs/zh/hive/current/reference/)** — 基于 Hadoop 的数据仓库与 SQL 工具中文指南
- **[Apache HBase 中文参考](https://github.com/apachecn/hbase-doc-zh)** — 建立在 Hadoop 之上的分布式 NoSQL 列式存储中文参考
- **[Apache Flume 用户手册](https://flume.liyifeng.org)** — 极佳的分布式日志采集与传输框架中文指南
