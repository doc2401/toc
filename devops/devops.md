# 运维与构建工具

> 现代 DevOps 容器化、服务器配置、版本控制及构建系统的核心参考文档。

### 🐳 容器化与集群 (Containers & Orchestration)
- **[Docker 官方文档](https://docs.docker.com/)** — Docker 引擎安装、Dockerfile 编写与 Compose 容器编排指南
- **[Kubernetes 官方中文文档](https://kubernetes.io/zh-cn/docs/)** — K8s 集群管理、Pod/Service 部署与核心概念中文手册

### 🌐 Web 服务器 (Web Server)
- **[Nginx 官方开发手册](https://nginx.org/en/docs/)** — Nginx 配置文件说明、反向代理、负载均衡与指令参考

- **[Apache Maven 核心参考](https://maven.apache.org/guides/index.html)** — Maven 生命周期、pom.xml 配置与常用插件指南
- **[Gradle 官方使用指南](https://docs.gradle.org/current/userguide/userguide.html)** — Gradle 构建脚本、多项目构建与核心 API 手册

### 🔄 持续集成与部署 (CI/CD)
- **[Jenkins 中文文档](https://www.jenkins.io/zh/doc/)** — 经典开源自动化服务器，用于构建、测试和部署的官方指南

### ⚙️ 自动化运维与配置管理 (IaC & Automation)
- **[Ansible 中文权威指南](https://ansible-tran.readthedocs.io/en/latest/)** — 简单、无代理的 IT 自动化与配置管理工具手册
- **[Terraform 官方文档](https://developer.hashicorp.com/terraform/docs)** — 多云架构基础设施即代码 (IaC) 的官方使用指南

### 📊 监控与系统可视化 (Monitoring & Logging)
- **[Prometheus 官方文档](https://prometheus.io/docs/introduction/overview/)** — 云原生时序数据库及监控告警系统核心参考
- **[Grafana 官方文档](https://grafana.com/docs/)** — 强大的多源指标分析展现与数据可视化平台手册
