# Spring Cloud & 其他

> 汇总常用的 Spring 生态其它关键子项目官方在线文档。

### 🌐 官方在线文档 (Online Official Docs)

- **[Spring Cloud](https://spring.io/projects/spring-cloud)** — 微服务架构全家桶开发指南
  - [Spring Cloud Reference Manual](https://docs.spring.io/spring-cloud/docs/current/reference/html/)
- **[Spring Security](https://spring.io/projects/spring-security)** — 身份验证、授权与安全防范框架
  - [Spring Security Reference Manual](https://docs.spring.io/spring-security/reference/)
- **[Spring Data](https://spring.io/projects/spring-data)** — 统一的关系与非关系型数据访问规范（JPA, Redis, MongoDB 等）
  - [Spring Data Commons Manual](https://docs.spring.io/spring-data/commons/docs/current/reference/html/)
- **[Spring Authorization Server](https://spring.io/projects/spring-authorization-server)** — 官方推荐的 OAuth 2.1 授权服务器实现
- **[Spring Integration](https://spring.io/projects/spring-integration)** — 企业集成模式（EIP）的轻量级实现
- **[Spring Session](https://spring.io/projects/spring-session)** — 跨实例分布式 Session 会话管理
- **[Spring AMQP / Kafka](https://spring.io/projects/spring-amqp)** — 基于 AMQP/Kafka 协议的的高级消息传递与数据流整合
- **[Spring Batch 中文文档](https://springdoc.tech/spring-batch/)** — 轻量级、全面的批处理框架官方文档中文版
