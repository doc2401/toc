# 跨端与原生开发

> 跨平台移动端应用、桌面端应用及小程序开发方案。

### 📱 移动端与小程序
- **[React Native](https://reactnative.dev/docs/getting-started)** — 使用 React 构建原生移动应用
- **[Expo](https://docs.expo.dev/)** — React Native 开发平台与工具链
- **[Flutter 文档](https://docs.flutter.cn/)** — Dart 跨平台 UI 工具包
- **[Capacitor](https://capacitorjs.com/docs)** — Web 原生移动应用容器接口
- **[微信小程序开发文档](https://developers.weixin.cn/miniprogram/dev/framework/)** — 官方微信小程序 API 与参考指南
- **[uni-app 官方文档](https://uniapp.dcloud.net.cn/)** — 基于 Vue 3 的多端发布跨平台框架
- **[Android 开发者文档](https://developer.android.com/docs?hl=zh-cn)** — Android 原生官方指南与 API 参考
- **[SwiftUI 官方文档](https://developer.apple.com/documentation/swiftui)** — Apple 声明式 UI 框架
- **[Kotlin Multiplatform](https://kotlinlang.org/docs/multiplatform.html)** — Kotlin 跨平台共享代码方案

### 💻 桌面端应用
- **[Electron 官方文档](https://www.electronjs.org/zh/docs/latest/)** — 使用 Web 技术构建跨平台桌面应用的官方文档
- **[Tauri](https://v2.tauri.app/zh-cn/start/)** — 基于 Web 前端与 Rust 的轻量级桌面应用框架
