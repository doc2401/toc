# 构建工具与 UI 体系

> 涵盖打包构建工具、CSS 体系、UI 组件库及 Web 基础技术。

### 🛠️ 现代构建工具
- **[Vite 官方文档](https://cn.vitejs.dev/)** — 极速的前端开发与构建工具官方指南
- **[Rspack](https://www.rspack.dev/zh/)** — 基于 Rust 的高性能构建工具，Webpack 替代方案
- **[Webpack 官方文档](https://webpack.js.org/concepts/)** — 模块打包机参考
- **[Rollup 官方文档](https://rollupjs.org/)** — JavaScript 模块打包器
- **[esbuild 官方文档](https://esbuild.github.io/)** — 极速 JavaScript 打包器
- **[Turborepo](https://turborepo.com/docs)** — JavaScript / TypeScript 多包仓库构建系统
- **[Zod](https://zod.dev/)** — TypeScript 优先的 Schema 校验库

### 🎨 CSS 与样式
- **[Tailwind CSS 文档](https://www.tailwindcss.cn/)** — 实用优先的原子化 CSS 框架中文参考
- **[Bootstrap](https://getbootstrap.com/docs/)** — 响应式 CSS 框架
- **[Sass 官方文档](https://www.sass.hk/docs/)** — 强大的 CSS 扩展预处理器
- **[Less 文档](https://lesscss.cn/)** — 好用的 CSS 预处理语言

### 🧩 UI 组件库
- **[Ant Design](https://ant.design/docs/react/introduce-cn)** — React 企业级 UI 框架
- **[Element Plus](https://element-plus.org/zh-CN/)** — Vue 3 UI 组件库
- **[Vuetify](https://vuetifyjs.com/en/getting-started/installation/)** — Vue Material Design 框架
- **[MUI](https://mui.com/material-ui/getting-started/)** — React Material UI 组件
- **[shadcn/ui](https://ui.shadcn.com/docs)** — 可复制粘贴定制的 React 组件
- **[Radix UI](https://www.radix-ui.com/primitives/docs/overview/introduction)** — 样式分离的无头 React UI 原语
- **[Headless UI](https://headlessui.com/)** — Tailwind 团队的无头 UI 组件

### 🪄 动画与可视化
- **[Motion (Framer Motion)](https://motion.dev/docs)** — React 声明式动画库
- **[Three.js](https://threejs.org/docs/)** — WebGL 3D 渲染引擎
- **[GSAP](https://gsap.com/docs/)** — 专业级 JavaScript 动画库
- **[Apache ECharts 官方文档](https://echarts.apache.org/zh/index.html)** — 强大的前端数据可视化图表指南
- **[D3.js](https://d3js.org/getting-started)** — 数据驱动文档可视化
- **[Chart.js](https://www.chartjs.org/docs/latest/)** — Canvas 简单图表

### 📖 Web 核心与测试库
- **[Vitest](https://vitest.dev/guide/)** — Vite 原生单元测试框架
- **[Playwright](https://playwright.dev/docs/intro)** — 端到端测试
- **[Cypress](https://docs.cypress.io/)** — Web 端到端测试工具
- **[Storybook](https://storybook.js.org/docs)** — UI 组件开发文档工具
- **[ESLint](https://eslint.org/docs/latest/)** — 代码静态检查
- **[Prettier](https://prettier.io/docs/)** — 代码格式化
- **[Can I Use](https://caniuse.com/)** — Web 前端兼容性速查
- **[jQuery API 文档](https://jquery.cuishifeng.com/)** — 经典操作库
