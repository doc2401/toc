# 前端框架与状态管理

> 涵盖主流的前端组件化框架、全栈框架以及状态与路由管理。

### ⚛️ 核心 UI 框架
- **[React 官方文档](https://react.dev/)** — 构建 Web 与原生交互界面的库
- **[Vue.js 中文文档](https://cn.vuejs.org/)** — 渐进式 JavaScript 框架
- **[Svelte 中文文档](https://svelte.dev/docs/introduction)** — 无虚拟 DOM 的编译型前端框架
- **[Qwik 官方文档](https://qwik.dev/docs/)** — 零 JS 水合、恢复延迟的 Web 框架
- **[SolidJS](https://www.solidjs.com/)** — 细粒度响应式的现代前端框架
- **[HTMX](https://htmx.org/docs/)** — 构建现代前端的 HTML 属性扩展
- **[Alpine.js](https://alpinejs.dev/)** — 轻量级响应式 JavaScript 框架
- **[Lit](https://lit.dev/docs/)** — Google 的 Web Components 库
- **[Turbo / Stimulus (Hotwire)](https://turbo.hotwired.dev/handbook/introduction)** — Rails 生态 HTML-over-the-wire 前端框架

### 🌍 现代全栈框架
- **[Next.js](https://nextjs.org/docs)** — React 全栈 Web 框架
- **[Nuxt](https://nuxt.com/docs)** — Vue 全栈 Web 框架
- **[SvelteKit](https://svelte.dev/docs/kit/introduction)** — Svelte 官方应用框架
- **[Astro](https://docs.astro.build/zh-cn/getting-started/)** — 内容驱动的快速 Web 框架
- **[Remix](https://remix.run/docs/en/main)** — 基于 Web 标准的 React 全栈框架

### 🚦 路由与状态管理
- **[React Router](https://reactrouter.com/)** — React 路由及全栈数据 API
- **[Redux Toolkit](https://redux-toolkit.js.org/)** — Redux 官方推荐工具集
- **[Zustand](https://zustand.docs.pmnd.rs/)** — 轻量级 React 状态管理库
- **[Jotai](https://jotai.org/docs/introduction)** — 原子化 React 状态管理
- **[Pinia 官方文档](https://pinia.vuejs.org/zh/)** — Vue 3 官方推荐状态管理
- **[TanStack Query](https://tanstack.com/query/latest/docs/framework/react/overview)** — 异步数据状态管理
- **[RxJS](https://rxjs.dev/guide/overview)** — JavaScript 响应式编程库
