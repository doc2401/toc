# 数据库文档

- **[PostgreSQL 官方文档](https://www.postgresql.org/docs/)** — PostgreSQL 当前版本与历史版本参考手册
- **[MariaDB 官方文档](https://mariadb.com/docs/)** — MariaDB Server、复制与集群文档
- **[菜鸟教程 - SQL 教程](https://www.runoob.com/sql/sql-tutorial.html)** — 基础 SQL 语法入门指南
- **[菜鸟教程 - MySQL 教程](https://www.runoob.com/mysql/mysql-tutorial.html)** — 适合初学者的 MySQL 数据库中文教程
- **[SQLite 官方文档](https://www.sqlite.org/docs.html)** — 轻量级嵌入式本地文件数据库官方指南
- **[菜鸟教程 - SQLite 教程](https://www.runoob.com/sqlite/sqlite-tutorial.html)** — 简单直接的 SQLite SQL 语法指南
- **[SQL Server 官方文档](https://learn.microsoft.com/zh-cn/sql/sql-server/)** — 微软企业级数据库引擎核心配置与 Transact-SQL 参考
- **[菜鸟教程 - SQL Server 教程](https://www.runoob.com/sql-server/sql-server-tutorial.html)** — SQL Server 基础操作与维护教程
- **[Oracle Database 帮助中心](https://docs.oracle.com/en/database/)** — 甲骨文关系型数据库官方技术文档与 SQL/PL-SQL 参考
- **[菜鸟教程 - Oracle 教程](https://www.runoob.com/oracle/oracle-tutorial.html)** — 经典 Oracle 数据库使用与 SQL 指南
