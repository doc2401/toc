# 前端技术索引

> 汇总现代前端开发、框架、构建工具与兼容性查询的经典网络手册。

### 🌐 Web 基础与规范
- **[MDN Web Docs](https://developer.mozilla.org/zh-CN/)** — HTML, CSS, JavaScript 的权威开放标准参考
- **[ECMAScript 6 入门](https://es6.ruanyifeng.com/)** — 经典深入的 ES6+ 标准中文教程（阮一峰）

### 📘 TypeScript
- **[TypeScript 官方文档](https://www.typescriptlang.org/docs/)** — 核心概念、配置选项与英文参考手册
- **[TypeScript 中文手册](https://wangdoc.com/typescript/)** — 简洁易读的 TypeScript 中文参考手册（社区维护）

### ⚡ 现代前端框架
- **[Vue.js 官方中文文档](https://cn.vuejs.org/)** — Vue 3 渐进式开发框架的官方中文学习教程与 API 参考
- **[React 官方中文文档](https://zh-hans.react.dev/)** — React 新版官方中文文档与核心概念说明
- **[Pinia 官方文档](https://pinia.vuejs.org/zh/)** — Vue 3 官方推荐的状态管理库

### 🛠️ 构建与样式
- **[Vite 官方中文文档](https://cn.vitejs.dev/)** — 极速的前端开发与构建工具官方中文指南
- **[Tailwind CSS 中文文档](https://www.tailwindcss.cn/)** — 实用优先的原子化 CSS 框架使用手册

### 🔍 兼容性与辅助工具
- **[Can I Use](https://caniuse.com/)** — Web 前端各类 HTML5/CSS3 特性在各大浏览器中的兼容性对比查询
- **[Nuxt.js](https://nuxt.com/)** — 基于 Vue 3 的 SSR / 全栈开发框架
- **[Next.js](https://nextjs.org/)** — 基于 React 的生产级 SSR / 全栈开发框架
