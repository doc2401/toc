# API、身份与安全

> 汇总 API 规范、RPC、身份认证、策略控制、供应链安全与应用安全参考文档。

### API 规范与协议
- **[OpenAPI Specification](https://spec.openapis.org/oas/latest.html)** — HTTP API 描述规范 `官方在线`
- **[Swagger 文档](https://swagger.io/docs/)** — OpenAPI 设计、文档与工具链 `官方在线`
- **[AsyncAPI](https://www.asyncapi.com/docs)** — 异步消息 API 描述规范 `官方在线`
- **[GraphQL](https://graphql.org/learn/)** — API 查询语言与运行时 `官方在线`
- **[gRPC](https://grpc.io/docs/)** — 基于 HTTP/2 与 Protocol Buffers 的 RPC 框架 `官方在线`
- **[Protocol Buffers](https://protobuf.dev/)** — 结构化数据序列化协议 `官方在线`
- **[tRPC](https://trpc.io/docs)** — TypeScript 端到端类型安全 API `官方在线`
- **[JSON:API](https://jsonapi.org/)** — JSON 资源 API 规范 `官方在线`
