# Node.js 与 JS/TS 生态

> JavaScript、TypeScript 基础、Node.js 运行时及各类 Web 框架。

### 🟢 语言基础与运行时
- **[Node.js 官方中文网](https://nodejs.cn/)** — 包含官方中文 API 文档、安装与教程
- **[TypeScript 官方中文文档](https://www.typescriptlang.org/zh/)** — 强类型的 JavaScript 超集，现代前端与 Node.js 开发标准
- **[Modern JavaScript Tutorial](https://zh.javascript.info/)** — 从基础到高级的现代 JS 系统教程
- **[MDN JavaScript 权威参考](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript)** — Mozilla 提供的权威 JS 库与语法核心参考
- **[Deno](https://docs.deno.com/)** — 安全的 JavaScript / TypeScript 运行时 `官方在线`
- **[Bun](https://bun.sh/docs)** — JavaScript 运行时、包管理器和构建工具 `官方在线`

### 🌐 服务端 Web 框架
- **[Express](https://expressjs.com/)** — Node.js 经典 Web 框架 `官方在线`
- **[NestJS](https://docs.nestjs.com/)** — 面向大型 TypeScript 服务端应用的模块化框架 `官方在线`
- **[Fastify](https://fastify.dev/docs/latest/)** — 高性能、插件化 Node.js Web 框架 `官方在线`
- **[Hono](https://hono.dev/docs/)** — 多运行时（Edge/Bun/Deno/Node）轻量级 Web 框架 `官方在线`
- **[Koa](https://koajs.com/)** — Express 团队的下一代 Node.js Web 框架 `官方在线`
- **[Elysia](https://elysiajs.com/)** — Bun 原生 TypeScript Web 框架 `官方在线`
