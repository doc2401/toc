# 语言参考手册

> 主流开发语言的官方文档与优秀中文社区资源汇总。

### 🐍 Python
- **[Python 3 官方中文文档](https://docs.python.org/zh-cn/3/)** — 最权威的 Python 语言参考、标准库与教程
- **[Python 标准库 API 手册](https://docs.python.org/zh-cn/3/library/index.html)** — 标准库的中文函数参考

### 🐹 Go (Golang)
- **[Go 官方文档](https://go.dev/doc/)** — Go 语言入门、语言规范与核心包 API
- **[Go 语言中文网](https://studygolang.com/)** — 中文 Go 开发者学习社区与技术分享
- **[Go 语言标准库中文版](https://studygolang.com/pkgdoc)** — 方便快捷的 Go 标准库中文查询工具

### 🦀 Rust
- **[Rust 语言官网](https://www.rust-lang.org/zh-CN/)** — Rust 语言官方入口与安装介绍
- **[Rust 语言圣经 (Rust Course)](https://course.rs/)** — 系统化、高质量的 Rust 中文学习教程与进阶指南
- **[Rust 程序设计语言 (The Book)](https://doc.rust-lang.org/book/)** — 官方英文经典教材
- **[Rust 标准库 API 速查](https://doc.rust-lang.org/std/)** — 官方标准库模块与函数文档

### 🟢 Node.js / JavaScript
- **[Node.js 官方中文网](https://nodejs.cn/)** — 包含官方中文 API 文档、安装与教程
- **[Modern JavaScript Tutorial](https://zh.javascript.info/)** — 从基础到高级的现代 JS 系统教程
- **[MDN JavaScript 权威参考](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript)** — Mozilla 提供的权威 JS 库与语法核心参考

### 📘 C / C++
- **[Cppreference 中文网](https://zh.cppreference.com/)** — 最权威、最全面的 C 和 C++ 标准库与核心语法中文在线手册
